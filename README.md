Official website: https://shareone.vip

This repository contains the ShareOne agent skill. It helps AI agents publish
HTML, Markdown, TXT, PDF, Word, and PowerPoint content as ShareOne share links,
with support for access passwords, watermarks, existing-link updates, and
review comments on text pages.

See [SKILL.md](./SKILL.md) for the full agent instructions.
